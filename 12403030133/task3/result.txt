第4小题：会话生命周期
键：exam:12403030133:session

实际SET返回True。

实际创建后输出：
{
  "value": "session-12403030133",
  "ttlSeconds": 5,
  "typeBeforeExpiry": "string"
}

实际等待后输出：
{
  "existsAfterWait": false,
  "ttlAfterWait": -2,
  "passed": true
}

结果说明：会话创建时有效期为5秒，等待6秒后键已过期。TTL返回-2，过期核验通过。会话键类型在过期前检查为string。
